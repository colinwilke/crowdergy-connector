# v3.36.1 — Steuerungs-Schritt: fehlender Text + Warmwasser-Entität als optional erklärt

Reine Übersetzungs-/Text-Korrektur im Config-Flow. Keine Funktions-, Schema-
oder HA-Version-Änderung, keine neuen Entity-/Preset-Slots → keine neue
Box-Vendor-Matrix-Zeile, keine Re-Provisionierung nötig.

## Bugfix

- Im Schritt **Steuerung** beim Hinzufügen eines Geräts (Optionen →
  „Gerät hinzufügen") zeigte Home Assistant den rohen Schlüssel
  `entity_vorlauf_temp_c` statt einer Übersetzung. Von den drei
  Steuerungs-Blöcken fehlten diesem einen die Texte für
  `entity_vorlauf_temp_c` / `entity_vorlauf_setpoint_c` (Label +
  Beschreibung) — sie sind jetzt ergänzt und in allen Flows (erstes Setup,
  Hinzufügen, Bearbeiten) identisch.

## Verbessert

- Die **Warmwasser-Entität** ist jetzt sichtbar als „(optional)"
  ausgezeichnet, und die Beschreibung erklärt, dass man das Feld leer lassen
  und stattdessen eine Steuer-Entität zuordnen kann.
- Die Beschreibung des Steuerungs-Schritts sowie die Felder
  `entity_climate` / `entity_water_heater` erklären jetzt, **was
  `climate`- und `water_heater`-Entitäten in Home Assistant sind** (das
  Präfix, was sie bündeln und wann man sie nutzt).
- `strings.json` (EN) und `translations/de.json` synchron gehalten.
