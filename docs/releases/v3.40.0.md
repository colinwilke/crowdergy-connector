# v3.40.0 — Fix: deleting an old device card no longer deletes the device

Bug-fix follow-up to the v3.38.0 hub-device redesign. No schema/telemetry/
dispatch/preset change. (v3.39.0 was released in parallel for unrelated
work; this is the next version.)

## Fixed

- **Deleting a leftover `Crowdergy_<Name>` device card in Home Assistant
  no longer deletes the real device on the Crowdergy backend.** Since
  v3.38.0 all entities live on the single "Crowdergy" hub device, so the
  old per-device cards are empty leftovers — but the card-delete handler
  still ran a backend device delete for any card removed, so tidying up an
  empty card silently deleted the live device it used to represent (and
  stripped its "Crowdergy AI" switch from the hub).

## Changed

- **Setup now prunes the old per-device cards automatically.** After the
  switches re-home to the hub, the connector detaches the stale
  `Crowdergy_<Name>` cards from the config entry, so Home Assistant clears
  them — you don't have to delete anything by hand.
- **The card-delete handler is non-destructive.** The live "Crowdergy" hub
  device can't be removed via a card delete; any other leftover card is
  just cleared, with no backend call. Removing a device is still done
  explicitly via Configure → Remove device.

## Notes for existing installs

After updating, the stale `Crowdergy_<Name>` cards disappear on their own —
no manual cleanup needed. If you already deleted old cards by hand before
this fix, those devices were removed on the backend; re-add them via the
setup wizard.
