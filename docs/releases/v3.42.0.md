# v3.42.0 — 1/3-phase switching for wallboxes (charge solar from ~1.4 kW)

Wallboxes that can switch between 1-phase and 3-phase charging (e.g. go-e
with its "nur 1" / "nur 3" / "Auto" phase select) previously charged with
a fixed 3-phase minimum of ~4.1 kW (6 A × 3 × 230 V) — so Crowdergy could
never dim the charging power onto a small solar surplus. A 3-kW roof
output was structurally unusable for PV-only charging.

With this release Crowdergy can charge **single-phase from ~1.4 kW**: the
solver picks the phase count explicitly per tick and commands it together
with the charging current.

## Added

- **Phase-switch entity (optional).** In the wallbox setup you can now map
  the box's phase-mode select entity, and in the charge-mode values step
  the two option strings for "1-phase only" / "3-phase only". Together
  with a mapped charging-current entity this reports the
  `wallbox_supports_phase_switching` capability to the backend.
- **Explicit phase commands.** `set_charge_mode` commands now carry
  `phases: 1|3` in power mode. The connector writes the phase select
  FIRST, then the charging current, then the mode — the same amps mean
  three times the power on 3 phases, so the coarse lever always lands
  before the fine one. The hold-loop re-writes the phase alongside
  current and mode.

## Notes

- **"Auto" is deliberately never written.** Under auto phase switching an
  externally computed ampere command is ×3-ambiguous (1- vs 3-phase); map
  only the two explicit options.
- Fully backward compatible: without the phase entity mapped nothing
  changes, and the `phases` command field is ignored fail-soft. The
  backend (≥ 2026-07-19) only sends it once the capability is reported.
