# v3.50.7 — hardening and fewer stray values

## Fixed

- **Numeric charge modes are kept inside the target entity's limits**, like
  every other numeric write. A value outside the limits is clamped and
  reported as a control problem instead of being written as-is.
- **Faster updates for second power sensors and discharge/feed-in counters:**
  their changes now arrive within seconds instead of with the next 30-s
  update.
- **No more ~2-minute hangs when the cloud is unreachable** while the live
  connection is being opened (connect timeout 30 s).
- **No blocking-call warning in Home Assistant** during setup and options
  flows: HTTP clients are created off the event loop.
- **Malformed cloud responses no longer stop telemetry** or damage the
  stored login; the connector logs one warning and carries on.
- **No invented power value for devices without a power sensor:** the
  power reading is left out instead of reported as 0 kW.

## Upgrading

Requires the backend version deployed 2026-10-24 (evening) so that
"power is not measured" keeps working for devices without a power
sensor. No entry-data change, no re-provisioning.
