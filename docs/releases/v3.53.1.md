# v3.53.1 — maintenance release

## Changed

- **Code cleanup, no functional change for current installations.** Lint
  configuration (ruff) with a CI step, modernised imports and type
  annotations, tidied comments.

## Removed

- The automatic cleanup of stale per-device cards left over from versions
  before v3.38.0, and the automatic control-mode inference for config
  entries created before v3.0. Installations set up with v3.38.0 or later
  are unaffected; older entries should be re-created once via
  *Configure → Add device*.

## Upgrading

No backend update required, no entry-data change.
