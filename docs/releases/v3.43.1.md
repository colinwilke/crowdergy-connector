# v3.43.1 — fix: empty config-flow menu on non-German Home Assistant

Users whose Home Assistant runs in **English** (the default) saw the
Crowdergy config flow with **only empty menu and field entries** — no
labels at all.

## Fixed

- **Ship `translations/en.json`.** Home Assistant loads config-flow
  translations at runtime **only** from `translations/<lang>.json`;
  `strings.json` is a developer source and is **not** read at runtime for
  a custom integration. Until now only `translations/de.json` was
  bundled, so any non-German UI language had no `en` fallback and rendered
  every entry blank. The English translations are now shipped as
  `translations/en.json` (structurally identical to `strings.json`).

## Notes

- German installations were never affected (`de.json` was already
  shipped).
- A test guard now asserts `translations/en.json` exists and that both
  `en`/`de` fully cover the `strings.json` keys, so a future menu/step
  addition can't silently ship without its translations.
- HACS pulls this release automatically; no re-provisioning needed.
