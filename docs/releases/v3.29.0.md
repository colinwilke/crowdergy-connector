## v3.29.0 — Kopplung per Pairing-Code + Geräte-Topologie

Feature-Release auf v3.28.1. Stellt das Onboarding auf **Pairing-Codes**
um (wie die Crowdergy Box) und ersetzt das alte „Im Haushaltsstrom
enthalten"-Häkchen durch die **Geräte-Topologie** des Backends.

### Neu

- **Onboarding per Pairing-Code:** Beim Verbinden gibst du jetzt einen
  Code aus der Crowdergy-App (Einstellungen → Verbindung) ein, statt
  E-Mail + Passwort. Home Assistant sieht NIE dein Passwort — funktioniert
  auch mit „Mit Apple anmelden". Gleiches Verfahren beim erneuten
  Verbinden (Reauth). Bestehende Verbindungen laufen unverändert weiter.

### Geändert

- **„Im Haushaltsstrom enthalten" entfällt:** Die Doppelzähl-Vermeidung
  läuft jetzt über die Geräte-Topologie (übergeordnetes Gerät pro Gerät),
  konfiguriert in der Crowdergy-App. Das Häkchen im Konfigurations-Dialog
  ist weg.

### Hinweise

- **Breaking (Alpha):** Neu-Setups + erneutes Verbinden nutzen
  Pairing-Codes; Email/Passwort-Felder sind raus. Bestehende Einträge
  brauchen nichts zu tun (Token-Refresh läuft weiter).
- Self-Hosted: die API-URL lässt sich beim Onboarding optional anpassen.
