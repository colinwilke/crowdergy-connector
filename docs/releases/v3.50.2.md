# v3.50.2 — local PV-surplus wallbox controller: safer surplus detection

Fixes three cases in which the local PV-surplus controller for wallboxes
(introduced in v3.49.0) could charge the car from the home battery or the
grid instead of from measured surplus.

## Fixed

- **A discharging home battery is no longer counted as surplus.** If the
  battery covered the wallbox, the grid read 0 kW and the controller kept
  charging. Battery discharge is now always subtracted; battery charging
  power still only counts as surplus once every listed battery has reached
  its state-of-charge threshold.
- **The controller state follows the measurement.** Start and stop are only
  committed after the writes went through; a failed write is retried after
  60 s. If the wallbox keeps drawing power without the controller having
  started it, the controller stops it again when there is no surplus, or
  takes it over and regulates the current when there is. A wallbox in its
  own firmware solar mode is left alone.
- **Frozen sensors are detected.** Grid, wallbox and battery power values
  older than 5 minutes are treated as missing; a running wallbox stops.

## Upgrading

No backend change needed. No entry-data change, no re-provisioning.
