# v3.55.0 — write counters per device

## Added

- **Crowdergy counts how often it writes to each device.** For every
  device the connector now keeps a daily count of the commands it sends
  to Home Assistant, split by role (for example charge current, charge
  mode, battery setpoint). For wallboxes it also counts charge starts
  and current changes made by the local solar regulator. The daily
  totals are reported together with the regular telemetry.
- The counters are observational only. They do not block, delay or
  change any command.

## Upgrading

Requires the current Crowdergy backend (already live). No entry-data
change. The counters live in memory and restart from zero after a Home
Assistant restart.
