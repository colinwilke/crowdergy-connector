# v3.53.2 — location sync fix

## Fixed

- **Location now reaches devices that already exist.** District, city and
  region were only sent to the backend when a device was created. Saving
  them later under *Configure → Basic settings* stored them locally only,
  so those devices stayed without a location (and out of the community
  map). Saving the basic settings now updates every existing device. If
  the backend cannot be reached, the form stays open with a connection
  error; saving again retries.

## Upgrading

No backend update required, no entry-data change. If you set your
location after adding devices, open *Configure → Basic settings* once
and press *Submit*.
