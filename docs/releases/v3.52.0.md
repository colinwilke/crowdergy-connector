# v3.52.0 — battery PV charging follows the measured surplus

## Added

- **Battery PV charging is regulated locally.** When the cloud asks the
  battery to charge from PV that would otherwise leave the house (for
  example into a wallbox in its own solar mode), the command now carries
  the meter to follow. The integration then adjusts the charge setpoint
  every 15 s to the measured surplus at that meter instead of holding one
  value for the whole 15-minute slot — so a passing cloud no longer makes
  the battery charge from the grid.
  - Never above the measured surplus; below the battery's minimum power
    for 30 s it holds (setpoint 0, no discharge); a missing or frozen
    reading sets 0 at once.
  - Any other battery command, Crowdergy AI off, or the command lease
    expiring ends the regulation. Without renewal for 1 h the battery
    returns to passive.
  - Remote-control consent, the write circuit breaker and the entity's
    limits apply as for every other write.

## Upgrading

Requires the backend version deployed 2026-10-25 that sends the meter to
follow; older backends keep the previous behaviour. No entry-data change,
no re-provisioning.
