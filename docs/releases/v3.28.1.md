## v3.28.1 — Fix: Hausverbrauchs-Sensoren wurden nicht gespeichert

Patch-Release auf v3.28.0. Behebt einen Defekt in der HC-Triade aus
v3.28.0 (Backlog #42): die vier Hausverbrauchs-Sensoren ließen sich zwar
im Konfigurations-Dialog auswählen, wurden beim Speichern aber **stumm
verworfen** — sie erreichten nie das Backend, und das
Hausverbrauchs-Diagramm blieb trotz korrekter Zuordnung leer.

### Behoben

- **HC-Triade-Persistenz:** `entity_home_consumption_pv_power`,
  `entity_home_consumption_battery_power`,
  `entity_home_consumption_grid_power` und der optionale
  `entity_pv_to_battery_power` werden jetzt korrekt in der
  Geräte-Konfiguration gespeichert (waren im Schema + im Telemetrie-Reader,
  fehlten aber in `_build_device_record` → Schema-zu-Persistenz-Lücke).

### Wirkung

Wer in v3.28.0 die Hausverbrauchs-Sensoren zugeordnet hatte, muss das
betroffene Gerät einmal neu speichern (Konfiguration → Gerät bearbeiten →
übernehmen), damit die Sensoren ankommen. Danach füllt sich das
Hausverbrauchs-Diagramm in der App.

### Intern

- Regressionstest deckt jetzt den vollständigen Round-Trip
  Schema → Persistenz ab (vorher nur Registry + Reader-Pfad).
