## v3.33.0

### Feature — Wallbox: variabler Ladestrom (6–16 A) analog Batterie

Wallboxen können jetzt — analog zum Batterie-Power-Setpoint — einen
**variablen Ladestrom** statt nur binär an/aus fahren.

Im Wallbox-Setup gibt es ein neues **optionales** Feld
**„Ladestrom"** (`entity_wallbox_charge_current_a`): eine
`number.*` / `input_number.*`-Entität, die den Ladestrom in Ampere setzt
(typisch 6–16 A). Mappst du sie, wählt die Crowdergy AI im **„An"/Power-Modus**
den optimalen Strom — z. B. um den PV-Überschuss feiner zu treffen oder
einen teuren Teil-Netzbezug zu vermeiden — und der Connector schreibt ihn
an die Entität (ganze Ampere), bevor er den Lademodus auf „An" stellt.

- **Leer lassen** = „An" bedeutet weiterhin volle Leistung (Verhalten
  unverändert).
- **Solar / Aus** tragen nie einen Strom — der **Solarmodus bleibt
  unverändert** (die Firmware folgt dort autonom dem PV-Überschuss).
- Der gehaltene Strom wird zusammen mit dem Modus periodisch
  nachgeschrieben (für Boxen, die ihren Strom selbst zurücksetzen).
- Optional auch als Crowd-Preset-Slot.

Benötigt das passende Backend (Capability-Flag
`wallbox_supports_charge_current` + variabler Solver-Strom). Additiv,
keine Re-Provisionierung nötig — bestehende Wallboxen ohne gemappte
Ladestrom-Entität verhalten sich exakt wie bisher.
