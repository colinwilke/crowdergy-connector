# v3.34.0 — Reworked config-flow texts, light/dark-safe icon, faster mode sync

No breaking changes, no re-provisioning needed. No HA-version bump, no
entity/preset schema changes → no new Box-vendor matrix row.

## Changed

- **Config-flow texts rewritten (German + English).** Every setup page now
  opens with a short explanation of what the mapping is used for; texts are
  shorter and use plain energy terms instead of technical jargon ("device
  profile" instead of vendor preset, "repeat command" instead of hold mode).
  The switching-value pages explain controlling via a target temperature
  (On = highest, Off = lowest desired temperature), and the entry pages link
  to [crowdergy.de](https://crowdergy.de).
- **Brand icon works on light AND dark backgrounds.** The full-bleed dark
  square was replaced by a rounded tile with transparent corners and a subtle
  rim.

## Fixed / internal (from #24)

- Manual changes to the charge-mode or cooling-control entity in HA now
  propagate to the backend via the event refresh (≤5 s) instead of waiting
  for the 30 s heartbeat.
- Loop-interval constants deduplicated into `telemetry_composer.py`
  (re-exported from `coordinator.py`); the contribute flow computes
  `integration_domain` only once.
