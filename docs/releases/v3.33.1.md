## v3.33.1

### Bugfix — Integration startete nach Update/Neustart nicht (kaputtes `de.json`)

`translations/de.json` enthielt im Feld-Text
`entity_wallbox_charge_current_a` (neu in v3.33.0) ein **nicht
escaptes** gerades Anführungszeichen (`Leer = „An" bedeutet …`). Das
beendete den JSON-String vorzeitig, sodass Home Assistants Loader
(`orjson`) beim Start abbrach:

```
Error while loading .../translations/de.json:
unexpected character: line 151 column 297
```

Folge: Die Integration konnte nach Installation/Update und HA-Neustart
**gar nicht erst geladen** werden.

Der Text trägt jetzt korrekte deutsche typografische
Anführungszeichen (`„An"`) und ist valides JSON. Zusätzlich prüft ein
neuer Regressions-Test jede ausgelieferte `*.json`-Datei hart auf
Parsebarkeit, damit so etwas nicht erneut bis zum Release durchrutscht.

Reiner Fix, keine Funktions- oder Schema-Änderung — keine
Re-Provisionierung nötig.
