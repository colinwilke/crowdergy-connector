# v3.54.1 — battery load following restarts after a stop

## Fixed

- **The battery resumes discharging once the load is back.** After the
  local load following (v3.54.0) had stopped a discharge, it only
  restarted above the inverter's minimum active power plus a margin. With
  a household load between the stop threshold and that minimum, the
  battery stayed on hold for as long as Crowdergy kept commanding a
  discharge. It now restarts just above the threshold that stopped it.

## Upgrading

No backend update required, no entry-data change.
