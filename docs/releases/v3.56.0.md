# v3.56.0 — far fewer repeated writes to your devices

## Changed

- **The charge mode is no longer re-written every 15 seconds.** With
  “Befehl wiederholen: auto” (the default) Crowdergy now writes the
  charge mode, charge current and phase of a wallbox or battery only
  when the device shows something else. Devices driven through a Home
  Assistant helper (`input_select`, `input_number`) and devices set to
  “immer” are refreshed as before.
- **A value the device does not take over is no longer repeated every
  30 seconds.** With “auto”, the wait doubles after each attempt, up to
  one hour. As soon as the device shows the value, the normal cadence
  returns. A new command is always written immediately.
- **Solar charging changes the charge current less often.** A running
  wallbox gets a new current only after the deviation held for 90
  seconds: upwards from 2 A, downwards from 1 A. A current change no
  longer re-writes phase and charge mode when the wallbox already shows
  them.

## Upgrading

No backend update required, no entry-data change.

If a wallbox or battery mapped to a real `select` or `number` entity
resets its charge mode on its own without Home Assistant showing it,
set “Befehl wiederholen” to “immer” for that device.
