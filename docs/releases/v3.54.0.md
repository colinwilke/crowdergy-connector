# v3.54.0 — battery discharge follows the load

## Added

- **A discharging battery no longer feeds the grid when the load drops.**
  Crowdergy commands a discharge power for a 15-minute slot. If the
  consumption behind the battery's meter fell below that power in the
  meantime, the rest went into the feed-in. The connector now lowers the
  discharge locally to the measured consumption at that meter:
  - It decides on the 60-second average, never on a single reading.
  - It only lowers — never above the power Crowdergy commanded.
  - Below the inverter's minimum active power it holds instead of
    discharging, and resumes once the load is back.
  - If a measurement is missing or frozen, it holds at once.
  - It ends with any other battery command, when Crowdergy AI is switched
    off, or when the cloud stays silent.

## Upgrading

Requires the backend version deployed 2026-11-17, which sends the
release for the local regulation; with an older backend nothing changes.
No entry-data change, no re-provisioning. The battery needs a mapped
power sensor, and so does the meter it sits behind.
