# v3.50.4 — reliable AI-off hand-over, no double-counted energy

## Fixed

- **Switching Crowdergy AI off in Home Assistant now hands the device
  over.** The switch updated its state before the cloud confirmed it, so
  the hand-over (battery to passive, heating/hot water off, holds and the
  PV charging controller stopped) never ran when the AI was switched off
  from Home Assistant. Switching from the app was not affected.
- **AI off ⇒ no writes:** the heating flow-temperature setpoint and the
  local PV charging controller no longer write to a device with the AI
  switched off.
- **No double-counted energy:** when a telemetry update was slow, a second
  update could start at the same time and report the same energy again.
  Overlapping updates are now skipped.
- **One odd sensor no longer stops all telemetry:** non-numeric states,
  NaN/inf values and a missing unit are ignored instead of aborting the
  update for every device.

## Housekeeping

- Unused code and constants removed; CI runs with read-only permissions.

## Upgrading

No backend change required, no entry-data change, no re-provisioning.
