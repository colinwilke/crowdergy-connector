# v3.53.0 — individually unavailable sensors are reported

## Added

- **Missing single values are reported, not just complete outages.**
  Every telemetry update now names the mapped measurement slots whose
  entity is currently `unknown` or `unavailable` in Home Assistant — even
  while the device's other sensors keep delivering (for example a meter
  reader with an empty battery next to a working inverter sensor). Only
  slot names are sent, never entity IDs.
  - Crowdergy shows a notice (and a push) once a value has been missing
    for 30 minutes, naming the device and the value in plain words.
  - The existing "no measurements" state (all sensors of a device dead)
    is unchanged.
  - A value dropping out or coming back is sent right away.

## Upgrading

Requires the backend version deployed 2026-10-30, which accepts the new
field — older backends reject the whole telemetry update. No entry-data
change, no re-provisioning.
