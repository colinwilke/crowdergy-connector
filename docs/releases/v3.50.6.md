# v3.50.6 — own telemetry echoes never switch devices, no invented power

## Fixed

- **A delayed echo of the connector's own telemetry no longer reverts a
  quick switch in Home Assistant.** The cloud echoes every telemetry
  update; the connector treated the on/off state in that echo as a
  command. Echoes are now marked by the cloud and ignored for control —
  commands from the app and the AI work as before.
- **No invented power value:** when a mapped power sensor is unavailable
  or not numeric, the power reading is left out instead of reported as
  0 kW. Devices without any power sensor still report 0 kW (the cloud uses
  that to show "power is not measured").

## Upgrading

Requires the matching backend version (deployed 2026-10-24) for the echo
fix; with an older backend the connector behaves as before. No entry-data
change, no re-provisioning.
